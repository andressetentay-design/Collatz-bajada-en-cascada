Title: Zenodo / DOI and metadata

To archive a snapshot and obtain a DOI (via Zenodo):
1. Connect your GitHub with Zenodo (https://zenodo.org/account/settings/github/).
2. Create a GitHub release (e.g., v1.0) — include release notes and link to datasets.
3. Zenodo will create a snapshot and mint a DOI. Use the DOI in future citations.
