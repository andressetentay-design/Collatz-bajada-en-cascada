Abstract (suggested):
We present a deterministic framework for the Collatz 3n+1 map based on signature classes: finite patterns describing the counts of odd operations and divisions by two until the first dyadic descent. We derive exact rational densities for first-drops across dyadic intervals, prove structural theorems on allowed signatures and modular balance, and provide computational verification across large intervals [2^28,2^30]. While not claiming a final proof of the Collatz conjecture, this approach yields a precise, verifiable formulation of the first descent mechanism and extensive numerical evidence supporting the theoretical predictions.

To prepare a submission to arXiv:
1. Convert repository material into a single LaTeX paper (include theorem statements, proof sketches, main lemmas). Use the repository README as base.
2. Produce a PDF with figures and essential tables. Avoid including huge data in the PDF—link to repository for full datasets.
3. Register at https://arxiv.org and submit under math.NT (Number Theory) or math.CO (Combinatorics) if appropriate.
4. Include a short ancillary file set (README, instructions to reproduce computations, small sample data) or point to GitHub and Zenodo DOI.
