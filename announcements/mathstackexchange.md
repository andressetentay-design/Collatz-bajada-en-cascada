Title: Structural approach to Collatz (signatures + exact densities)

Post for Math StackExchange / Community

Body:

Hi,

I created a repository that studies the Collatz 3n+1 map via "signatures": sequences characterized by the number of odd steps (A) and divisions by two (B) until the first strict descent below the starting dyadic block I_k = [2^k,2^{k+1}-1]. The project contains precise density formulas, a set of 20 deterministic theorems about signature classes and balance, and computational verification across [2^28,2^30].

Included:
- Readme with definitions and theorems
- Data and logs
- Reproducible Python script

Link: https://github.com/andressetentay-design/Collatz-bajada-en-cascada

Questions welcome. I'm happy to clarify definitions or post smaller examples.
