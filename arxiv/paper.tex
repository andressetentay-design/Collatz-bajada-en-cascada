\begin{abstract}
We present a structural (non-probabilistic) framework for the Collatz 3n+1 map based on signature classes: finite patterns describing counts of odd operations and divisions by two until the first dyadic descent. We state the main deterministic theorems describing allowed signatures and derive exact rational densities for first-drops across dyadic intervals. Computational verification on large intervals supports the theoretical predictions. This skeleton contains placeholders for theorem statements, proof sketches and figures. Full datasets and code are provided in the repository.
\end{abstract}
